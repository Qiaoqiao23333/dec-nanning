# 栖居 · 三维软装工作室 v2

浏览器访问已发布私有页面，或在本目录运行 `python3 -m http.server 8766 --directory dist`。根目录 `栖居-软装布置.html` 为完整离线版本，可双击打开；依赖已内嵌。

## 操作
- 点击房间名称：进入该房间独立设计，其他房间家具隐藏，前墙自动降低；完整墙体开关显示真实236cm墙高。
- 拖家具：移动；拖空白：旋转视角；Shift拖动：平移；滚轮：缩放。R旋转，方向键微调，Delete移除。
- 墙面设计：先在原房间内悬停高亮、点击选择墙面；平滑拉近至正对墙视角，保留墙前家具。点击“重新选墙”返回房间。添加挂画、圆镜、置物架、壁灯；可拖动或输入宽高、水平中心距左侧和离地中心高度。边界自动限制。Alt点击墙面也可进入。
- 房屋档案提供厨房/客卫与主卫/卧一交界定位。
- 旧版布局自动迁移。撤销重做、JSON导入导出同时包含家具和装饰。采购清单只统计真实家具，装饰为设计占位。

## 模型与校正
沿用原配平坐标。用户确认问题为墙体相互压叠，故保留实测平面位置；矩形墙体求并集只生成外露表面，排除内部/重复面；Three.js WebGL深度测试解决旧版二维画家排序穿插。墙高2360mm，门高沿用2100mm假设，门上横梁260mm。阳台栏板/飘窗台保留原高度。

家具使用圆角几何、曲木杆件、坐垫、纹理与阴影进行细化，属程序化模型而非品牌官方扫描模型。墙饰是通用设计占位，圆镜为金属质感示意、不做实时反射。精装地面保留。

## 验证
`npm test` 验证墙面并集无内部面、两处交界可选、236cm墙高与门梁、装饰边界，以及T交界合并面积。浏览器验证房间/墙面切换、挂画添加和旧方案迁移；需要支持 WebGL 2 的浏览器。
